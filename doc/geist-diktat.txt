*geist-diktat.txt*    Dictation at the cursor via the geist engine

==============================================================================
INTRODUCTION                                                   *geist-diktat*

geist-diktat.nvim toggles local speech-to-text: a diktat pipeline
(arecord | diktat) runs as a background job; each spoken utterance
arrives as one line and is put into the buffer at the cursor with
|nvim_put()| — programmatic insertion, so modal editing is never confused
by dictated text (unlike keyboard-injection tools).

Requires the diktat binary and the model (see the repo README, or the
.deb: `geist-diktat setup`).

==============================================================================
COMMANDS                                                             *:Diktat*

:Diktat                Toggle dictation. The status is exposed as
                        `vim.g.geist_diktat_active` for statuslines.

==============================================================================
SETUP                                                    *geist-diktat-setup*

No setup call is required for the defaults. To override: >lua

    require("geist-diktat").setup({
        binary = "diktat",     -- path to the diktat binary
        model  = "~/.local/share/geist-diktat/gemma4-e2b-Q4_K_M.gguf",
        rms    = 300,           -- VAD threshold (mic/room dependent)
        suffix = " ",           -- appended after each utterance
        cmd    = nil,           -- full pipeline override (testing/advanced)
    })
<
Install with lazy.nvim: >lua

    { "geisten/geist-diktat" }
<
The plugin lives at the repo root (lua/, plugin/, doc/) — plugin managers
need no subdirectory support.

Health check: `:checkhealth geist-diktat`
